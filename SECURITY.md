# Security Policy

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/HeiGeAi/HeiGe-Design/security/advisories/new)
and include the affected version, reproduction steps, impact, and proposed
mitigation when available.

Do not attach private source pages, credentials, or proprietary design assets.
Use a minimal redacted reproduction instead.
